# Micronaut Serde Jackson

[English](README.md) | [简体中文](README.zh-CN.md)

[`micronaut.serde.jackson`](micronaut/serde/jackson/module.norm) provides the Jackson runtime implementation of Micronaut Serialization 3.1.1. The [samples](samples/README.md) show typed serialization and deserialization through an independent consumer module.
